# 🤖 Robolillo 2.0

Bot de Discord con música, descargas, moderación, juegos e IA.

## 🚀 Funciones
- 🎵 Música con cola de reproducción
- 📥 Descargas de YouTube, Instagram y TikTok
- 🎮 Comandos de diversión
- 🎲 Juegos interactivos
- 🔨 Moderación
- 🌐 Soporte en español e inglés
- 🤖 IA con Claude
